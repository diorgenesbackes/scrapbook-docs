## Objetivo e limite da entrega

Permitir criar, listar, consultar e editar eventos, com capa padrão, boas-vindas e abertura imediata/programada. Entregar o caminho React → API → PostgreSQL usando identidade sintética explicitamente habilitada apenas no ambiente local.

Autenticação real permanece adiada. Convites, capa personalizada/upload, contribuições, galeria, exclusão, consumidor de primeiro registro, serviços AWS, envios externos e pipelines ficam fora desta story. A base com 47 changesets/33 tabelas já existe; este planejamento não a reconta como entrega nova e não prevê DDL ou migrations EF.

O FDD continua uma proposta até as decisões de implementação serem registradas. Os cartões preservam H-01…H-05, as fronteiras dos módulos e os 26 critérios da seção 9. Não há resultado de implementação ou teste comprovado pela criação do planejamento.

Usar as listas já existentes: Backlog → Todo → Doing → Test → To Deploy, quando aplicável → Done. Este planejamento não cria infraestrutura de publicação nem declara deploy realizado.
